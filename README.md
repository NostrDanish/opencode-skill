# opencode-skill

Agent skill for the [OpenCode](https://opencode.ai) CLI.

`SKILL.md` is host-agnostic (Cursor shell / tmux, or OpenClaw spawn). Config
and failure tables live in `references/`.

Pair with [mkstack-skill](https://github.com/NostrDanish/mkstack-skill) when
scaffolding a Nostr web client from the MKStack template.
